中键自动滚动，浏览器之外也能用。

浏览器（Chromium / Firefox）是在**页面内部**实现这个功能的，所以别的程序天生没有。这个工具把它做成系统级的：
**中键单击 → 锚点出现 → 指针拉开就持续滚，拉得越远越快 → 再点一下停。**

手感不是调出来的，参数全部来自浏览器源码。

## 安装

下载 `MidScrollAnywhere.exe`，双击即可（单文件、自带运行时、不需要安装 .NET）。
托盘会出现一个四箭头圆形图标，无主窗口。

## 用法

1. 在任意能滚动的程序里（记事本、资源管理器、Word、VS Code…）**中键单击**
2. **指针拉开** → 开始滚，越远越快；回到按下点附近 → 停住（仍是激活状态）
3. **按下任意鼠标键 / 任意键盘键** → 停止。这次点击会被吞掉，不会顺带选中文字

托盘菜单：启用/禁用、切换曲线、把当前前台程序加入忽略列表、设置。

## 与浏览器的对应关系

| 项目 | Chromium 源码依据 |
|---|---|
| 速度公式 | `v = 8×10⁻⁶ × \|d\|^2.2` px/ms，无上限（`blink::AutoscrollController`） |
| 死区 | 每轴 **15 DIP 矩形**；单帧 <0.1px 丢弃，实际约 21 DIP 起步 |
| 取消规则 | 任意鼠标键 / 任意按键 / 前台窗口变化；移出窗口、滚轮**不**取消 |
| 点击语义 | 只做 Toggled：点一下持续滚，下一次点击停 |
| 中键转发 | 中键照常发给程序（开链接、终端粘贴、CAD 平移都保留） |
| 锚点 | 浏览器是把指针换成系统平移光标，本工具自绘同款 |

Firefox 曲线同样来自源码（`AutoScrollChild.sys.mjs` 的 `accelerate()`：`val=d/12`，`val×√\|val\|∓1`，px/20ms）。

采样对照：

```
Chromium: 100px→201px/s  200px→923px/s  300px→2253px/s  500px→6931px/s
Firefox : 100px→1153px/s 200px→3352px/s 300px→6200px/s 500px→13398px/s
```

## 它会自己避开的地方

- **六大浏览器**（Chrome / Edge / Firefox / Brave / Opera / Vivaldi）：本身已经支持，避免双重滚动
- **全屏游戏 / 演示模式**：系统级全屏判定 + 光标隐藏/锁定 + 无边框全屏几何，三条信号任一命中就**完全不介入**（不注入、不换光标）
- **提权窗口**：不做提权注入，静默不生效

## 诚实的限制

滚轮消息的量化粒度是硬墙：`WHEEL_DELTA = 120`，一格滚多少像素由目标程序自己决定。
浏览器内部是连续像素滚动，浏览器之外只能"喂滚轮"，所以：

- 能吃小 delta 的程序（Chromium/Electron、部分 WPF/UWP）→ 接近平滑
- 只认整 120 的老程序 → 会一格一格跳，设置里勾"只发整格"更稳但更顿

这是数学限制。设置里的"最小发送单位 / 行高 / 每格行数 / 速度倍率"就是给这些差异留的旋钮，还支持按程序覆盖。

完整差异清单、配置字段说明、验收清单见仓库 README。

## 自检

```
MidScrollAnywhere.exe --selftest
```

无界面、不动光标，检查曲线采样、守卫探针、钩子安装/卸载、以及 `WM_MOUSEWHEEL` 是否真能让可滚动窗口滚动。
